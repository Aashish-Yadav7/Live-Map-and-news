# GitHub Repository Setup

## Description

Interactive 3D globe that visualizes live global news and real-world events by geographic location.

## Topics

```
threejs react typescript data-visualization news-api geospatial supabase real-time interactive-map 3d-globe
```

## Steps to Push

1. Create a new repository on GitHub (github.com/new)
   - Name it whatever you like (e.g. `global-news-globe`)
   - Set the description to: `Interactive 3D globe that visualizes live global news and real-world events by geographic location.`
   - Add these topics (Settings → General → Topics):
     `threejs` `react` `typescript` `data-visualization` `news-api` `geospatial` `supabase` `real-time` `interactive-map` `3d-globe`

2. Connect and push from your terminal:
```bash
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO.git
git push -u origin main
```

3. Done! Your code is on GitHub.
